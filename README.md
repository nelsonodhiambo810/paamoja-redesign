# PaaMoja Initiative - Web Redesign Prototype

A modern, full-stack web application built to empower the youth of Mathare Valley. This prototype modernizes the organization's digital footprint and introduces a custom content management system (CMS).

## 🚀 Key Features

* **Custom Admin CMS:** Built-in Django admin panel allowing non-technical staff to update Programs, News, and Success Stories dynamically.
* **Premium UI/UX:** Fully responsive, mobile-first design using Bootstrap 5, custom typography (Poppins), and fluid CSS hover animations.
* **Donation Portal:** Integrated M-Pesa payment prototype modal to drive fundraising.
* **Dynamic Storytelling:** Animated JavaScript impact counters and a database-driven "Voices of Mathare" testimonial slider.

## 🛠️ Tech Stack

* **Backend:** Python, Django 6.0, SQLite
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Architecture:** MVT (Model-View-Template)
